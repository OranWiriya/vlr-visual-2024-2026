# Raw data

Drop the three Kaggle event datasets here, each in its own folder:

```
data/raw/
  vct-2024-all-events/      # Complete VCT 2024 – All events (includes Masters Shanghai)
  masters-toronto-2025/     # Valorant Masters Toronto 2025
  champions-paris-2025/     # Valorant Champions 2025 Paris
```

Sources:

- https://www.kaggle.com/datasets/piyush86kumar/valorant-champions-tour-2024-all-events
- https://www.kaggle.com/datasets/piyush86kumar/valorant-masters-toronto-2025
- https://www.kaggle.com/datasets/piyush86kumar/valorant-champions-tour-2025-paris

The raw CSVs are git-ignored. Only the trimmed, aggregated data used by the
site will be committed.
